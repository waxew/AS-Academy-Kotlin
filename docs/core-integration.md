# اتصال Kotlin Course به AS Academy Core

این ریپو Course Package است، نه محل پیاده‌سازی مجدد اپ-shell.

## از Core مصرف می‌شود
- Navigation / Drawer / Profile
- Design System و RTL
- Database و migration infrastructure
- Content importer/updater
- Progress, Search, Bookmark
- Quiz, Exercise, Project engines
- Glossary و Achievement
- Settings, Backup, Update
- Code Runner framework

## در این ریپو باقی می‌ماند
- manifest و metadata دوره
- lesson/exercise/quiz/project content
- Kotlin code samples
- glossary و branding
- Kotlin-specific runner adapter/config در صورت نیاز

## قانون
هر قابلیت قابل استفاده در دو یا چند دوره ابتدا باید در `AS-Academy-Core` ساخته شود. این ریپو فقط configuration یا content اختصاصی Kotlin را نگه می‌دارد.
