# راهنمای تولید محتوای Kotlin

هر درس باید: هدف روشن، توضیح فارسی، مثال قابل اجرا، خروجی/نکته در صورت نیاز، تمرین و لینک آزمون داشته باشد. شناسه منتشرشده تغییر نمی‌کند.

## استاندارد مثال‌ها
1. مثال حداقلی و قابل اجرا باشد.
2. نام‌گذاری Kotlin idiomatic باشد.
3. از `!!`، global scope و mutable state بی‌دلیل پرهیز شود.
4. برای coroutine، lifecycle/cancellation توضیح داده شود.
5. برای Android، business logic از UI جدا بماند.
6. برای Backend، secret در سورس قرار نگیرد.

## سطح‌بندی
مبانی: syntax و mental model. مقدماتی: مدل‌سازی و تست. پیشرفته: type system و concurrency/build. تخصصی: محصول واقعی و production.
