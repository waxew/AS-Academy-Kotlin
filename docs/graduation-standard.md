# استاندارد اتمام دوره Kotlin

هنرجو زمانی دوره را کامل کرده است که فقط درس‌ها را مشاهده نکرده باشد، بلکه خروجی قابل ارزیابی تولید کند.

## حداقل معیارها
- تمام سطح مبانی و مقدماتی تکمیل شود.
- حداقل 80٪ Quizها با امتیاز 70٪ یا بالاتر پاس شوند.
- حداقل 12 تمرین، شامل 3 تمرین advanced/specialist، حل شوند.
- پروژه‌های `kt-prj-001` و `kt-prj-002` تکمیل شوند.
- حداقل یکی از مسیرهای Android، Backend یا Multiplatform با یک پروژه تخصصی تکمیل شود.
- Capstone نهایی شامل README، تست، CI و مستند release باشد.

## معیار کدنویسی
کد باید compile شود، naming روشن داشته باشد، global mutable state غیرضروری نداشته باشد، خطاها را کنترل کند و برای منطق مهم تست داشته باشد.
