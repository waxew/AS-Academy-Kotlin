# Solutions

Solutionها برای مقایسه بعد از تلاش هنرجو هستند، نه برای کپی مستقیم. هر solution باید خوانا، تست‌پذیر، idiomatic و متناسب با سطح تمرین باشد.

این پوشه **جزء محتوای تکمیلی Course Package** است. موتور عمومی نمایش/قفل‌گشایی Solution باید در `AS-Academy-Core` پیاده‌سازی شود و Course فقط پاسخ یا rubric اختصاصی خود را نگه دارد.

Canonical examples:

- `kt-ex-fnd-001.kt` — ماشین حساب تخفیف و validation پایه
- `kt-ex-beg-004.kt` — value class و domain ID
- `kt-ex-adv-003.kt` — coroutine testing و virtual-time strategy
- `kt-ex-adv-004.kt` — constructor injection و fake dependency
- `kt-ex-adv-005.md` — blueprint ماژول‌بندی و dependency boundaries
- `kt-ex-spc-007.md` — rubric بررسی Production Readiness

برای تمرین‌های expert الزاماً یک فایل کد کامل بهترین پاسخ نیست. در موضوعاتی مانند architecture، security، release engineering و observability، rubric و evidence مورد انتظار از یک «جواب آماده» آموزشی‌تر است.
