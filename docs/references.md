# منابع مرجع دوره

منابع اصلی برای بازبینی فنی محتوا:

- Kotlin Documentation و Language Reference
- Kotlin Standard Library API
- Kotlin Coroutines documentation
- Gradle Kotlin DSL documentation
- Android Developers - Kotlin / Jetpack Compose / Architecture
- Ktor documentation
- Spring Framework / Spring Boot Kotlin documentation
- Kotlin Multiplatform documentation

## سیاست نسخه
محتوای syntax و API نسخه‌حساس باید پیش از release minor/major دوباره بررسی شود. شماره نسخه مرجع در `course/manifest.json` نگهداری می‌شود.
